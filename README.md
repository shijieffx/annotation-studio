# 图像标注工作台 · Annotation Studio

浏览器里的图像标注工具：矩形框、多边形、关键点、文本四种标注方式，支持多图管理、撤销重做、快捷键与三种格式导出。

**纯前端应用，零后端依赖** —— 图片只在浏览器内存中处理，不上传任何服务器。

技术栈：**Konva.js**（Canvas 图层渲染）· Vue 3 · TypeScript · Vite

> **仓库地址**：https://github.com/shijieffx/annotation-studio
>
> **在线体验**：https://park-ops-platform.app.workbuddy.host/annotation/
> （与另一个作品共用域名，挂在其 `/annotation/` 子路径下）

---

## 快速体验

打开应用后点左上角「**示例图片**」即可直接开始标注，无需准备任何素材。

本地运行：

```bash
npm install && npm run dev     # http://localhost:5180
```

> 部署说明：本项目为纯静态产物，线上是与「园区综合运维管理平台」共用同一个域名与端口。
> 构建后把 `dist/` 的内容同步到该项目的 `public/annotation/`（它会在构建时被复制进 `dist/`），
> 即可通过 `/annotation/` 访问。本项目用 `base: './'` 构建，资源为相对路径，挂在任意子路径下都能正常工作。

## 功能

### 标注能力

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 选择 | `V` | 点选标注、拖动调整位置 |
| 平移 | `H` | 也可按住空格临时切换，或用鼠标中键 |
| 矩形框 | `R` | 拖拽绘制，松手即成框 |
| 多边形 | `P` | 逐点单击添加顶点，`Enter` 或双击闭合，`Esc` 取消 |
| 关键点 | `K` | 单击落点，适合关键点检测场景 |
| 文本 | `T` | 单击后在弹窗中输入内容 |

### 画布交互

- **缩放**：滚轮以指针为中心缩放（5% ~ 1200%），左下角可「适应窗口」或回到 100%
- **平移**：空格 + 拖拽 / 中键拖拽 / 平移工具
- **渲染**：三层分离——底图、标注、绘制草稿，拖动标注时不重绘底图

### 标注管理

- **多图支持**：一次导入多张图，左侧列表切换，角标显示每张图的标注数
- **类别体系**：8 个预设类别 + 自定义类别；**同名类别跨图片同色**（按名称哈希稳定映射，刷新不变色）
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`，50 步深度，覆盖增删改
- **删除**：选中后按 `Delete`，或在右侧列表点删除
- **类别分布**：实时统计当前图片的类别占比

### 导出

| 格式 | 内容 |
|---|---|
| **自用 JSON** | 结构最完整（含 type / label / 坐标），可再次导入本工具继续编辑 |
| **YOLO txt** | 每行 `classId cx cy w h`，坐标已按图像尺寸归一化到 0~1 |
| **COCO json** | 含 `bbox` 与 `segmentation`，可直接用于主流检测 / 分割训练框架 |

导出前可在弹窗内**实时预览**内容，确认无误再下载。

## 技术要点

### 1. 三层画布结构

```
Stage
├── bgLayer    底图（listening: false，不参与事件）
├── shapeLayer 标注层（可交互、可拖动）
└── draftLayer 绘制草稿（listening: false）
```

拖动标注时只有 shapeLayer 重绘，底图不受影响。草稿层独立也让「正在画的框」与「已完成的标注」互不干扰。

### 2. 坐标系统一为图像坐标

所有标注数据存的是**图像坐标系**下的值，与画布缩放、平移完全无关。

```ts
// 屏幕坐标 → 图像坐标
stage.getRelativePointerPosition()
```

这样导出时不需要任何反向换算，缩放画布也不会让标注漂移。

### 3. 数据模型是唯一事实来源

Konva 节点每次由数据模型重建（`destroyChildren()` + 重新构建），而不是双向绑定。

- **好处**：不会出现「节点位置改了但数据没同步」的漂移；撤销 / 重做只需替换数据数组，画布自动跟上。
- **代价**：每次变更重建节点。在千级标注量下实测无感知（本项目的目标场景），若需要万级标注则应改为增量更新。

### 4. 撤销 / 重做用快照栈

用快照而非命令模式：标注数据量可控，快照实现简单、**不会出现命令回滚不彻底**的情况（命令模式的经典坑是「复合操作只回滚了一半」）。栈深度限制 50 步控制内存。

> 一个由此发现的真实问题：Konva 自带双击判定（默认 400ms 窗口）。
> 连续快速点击多边形顶点时会被识别成「双击」，触发闭合逻辑。原先顶点不足就直接清空，
> 导致用户刚点出来的顶点莫名消失。现在改为**顶点不足时保留已有顶点并给出提示**。

### 5. 体积控制

| 项 | 大小 |
|---|---|
| JS（含 Konva + Vue） | 289 KB（gzip 95 KB） |
| CSS | 8.6 KB |

工具图标用**内联 SVG**，没有引入图标库；`base: './'` 让产物可以直接丢到任意子目录的静态托管。

## 快速开始

```bash
npm install
npm run dev        # 开发：http://localhost:5180
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
npm run typecheck  # 类型检查
```

> 用 `npm install --ignore-scripts` 跳过脚本安装即可（esbuild 的平台二进制包会正常落地）。

## 自测

```bash
npm run build
npm run preview &
node scripts/smoke.mjs          # 对 http://127.0.0.1:5180 跑冒烟测试
```

`scripts/smoke.mjs` 用系统 Edge 的 CDP 协议做**真实交互测试**，不只是检查元素存在：

1. 页面骨架与工具就位
2. 载入示例图片
3. **模拟鼠标拖拽，真实绘制一个矩形**，校验标注数与类别
4. 撤销 / 重做校验
5. 连续点击绘制多边形并按 `Enter` 闭合
6. 关键点落点、快捷键切换工具
7. 打开导出弹窗，校验 JSON / YOLO 预览内容与实际标注一致
8. 全程收集控制台报错

当前 **24 项断言全部通过**，并输出每一步的截图便于人工复核。

## 已知边界

- 多边形暂不支持拖动顶点微调（可删除后重画）。
- 图片仅存在浏览器内存中，刷新即清空；未做本地持久化（IndexedDB）。
- 导入只支持本工具导出的 JSON，未做 COCO / YOLO 的反向导入。
- 未做多人协同与标注审核流程。
